## Project Overview
This project focuses on data cleaning and visualization using Python. I used the Taxis dataset from Seaborn to understand taxi trips, fares, distances, tips, and payment methods.

## Libraries Used
- Pandas
- Matplotlib
- Seaborn

## Dataset
**Dataset Name:** Taxis Dataset  
**Source:** Seaborn (`sns.load_dataset("taxis")`)

## Tasks Completed

### 1. Data Cleaning
- Checked missing values.
- Filled missing values using mode and median.
- Removed rows with missing critical values.

### 2. Data Visualization

**Matplotlib / Pandas:**
- Line Chart – Fare over time
- Bar Chart – Total fare by pickup borough
- Pie Chart – Payment method distribution
- Histogram – Trip distance distribution
- Box Plot – Tips by pickup borough

**Seaborn:**
- Count Plot – Number of trips by borough
- Scatter Plot – Distance vs fare
- Heatmap – Correlation between numerical columns
- Pair Plot – Relationships between numerical columns
- Violin Plot – Fare distribution by payment method

## Conclusion
Through this assignment, I learned how to clean data and create different types of charts using Python. These visualizations helped me understand taxi trip patterns, fare distribution, and relationships between numerical columns.
